## 3주차: 네 페이지, 네 가지 분위기

- GitHub Pages URL: 你的 GitHub Pages URL

### 페이지별 스타일
- 프론트페이지: 깔끔하고 간단한 분위기 / `page-home` class와 기본 CSS 적용
- 장소 1: 따뜻하고 편안한 분위기 / `page-road` class와 배경색, 테두리 CSS 적용
- 장소 2: 밝고 편안한 분위기 / `page-dining` class와 흰색 패널, 둥근 모서리 CSS 적용
- 장소 3: 어두운 분위기 / `page-gym` class와 어두운 배경, 강조색 CSS 적용

### 모바일 스타일
- 적용한 @media 조건: `max-width: 600px`
- 모바일에서 특별히 바뀌는 부분과 이유: 화면 폭을 줄이고 패널과 제목의 크기를 조정하여 휴대전화에서도 보기 편하게 만들었다.
- 휴대전화에서 네 페이지를 확인한 결과: 네 페이지 모두 화면에 맞게 표시되었다.
